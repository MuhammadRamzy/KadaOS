# Code of conduct

Treat everyone at this counter the way a good thattukada does: warmly, patiently, and the same whoever they are.

- Be respectful and assume good intent. Disagree about code, not people.
- No harassment, discrimination, personal attacks, or sharing other people's private information.
- Help newcomers; everyone was new to Hyprland once.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders.
Report problems privately through the repository's **Security** tab (private report) or by contacting a maintainer.

This code adapts the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
